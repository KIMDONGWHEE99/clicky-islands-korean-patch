# Clicky Islands 한국어 패치 1.0.1

[**한글패치 ZIP 다운로드 — 약 7.6MB**](https://github.com/KIMDONGWHEE99/clicky-islands-korean-patch/releases/download/v1.0.1-r1/CLICKY_ISLANDS_KOREAN_PATCH_1.0.1_r1.zip) · [버전·검증 안내](docs/VERIFICATION.md) · [변경 이력](CHANGELOG.md)

Clicky Islands의 Windows Steam 버전을 위한 비공식 한국어 패치입니다. **Steam 앱 4178790 / 빌드 26823841**(게임 안 표시 1.1.2)를 기준으로 만들었습니다. 원본 게임을 설치한 상태에서 적용하는 차이 패치이며, 게임 원본 파일은 들어 있지 않습니다.

> **게임이 업데이트되면 패치가 사라집니다.** 이 게임은 업데이트가 잦고, Steam이 파일을 새로 받으면 한국어가 없는 원본으로 돌아갑니다. 설치기는 빌드가 다른 게임에는 적용하지 않고 "게임 버전이 다르거나 파일이 변경됐습니다"라고 알립니다. 그 경우 새 빌드용 판이 올라올 때까지 기다려 주세요.
>
> 이전 판 1.0.0은 빌드 26701014 전용이라 지금 게임에는 설치되지 않습니다. 이전 판을 설치했던 분은 따로 제거할 필요 없이 이 판의 `Install.cmd`만 실행하면 됩니다.

## 설치·제거

1. 게임을 종료하고 위의 **한글패치 ZIP 다운로드**를 누릅니다.
2. ZIP 전체를 새 폴더에 풉니다.
3. `Install.cmd`를 실행합니다. 게임 위치가 자동으로 나타나면 [설치]를 누르고, 찾지 못하면 `Clicky Islands.exe`가 있는 폴더를 고릅니다.
4. Steam에서 게임을 실행합니다. Windows가 한국어이면 처음부터 한국어로 시작합니다. 영어로 나오면 설정 → 언어 → **한국어**를 누릅니다.

제거하려면 같은 묶음의 `Remove.cmd`를 실행합니다. 중단된 설치는 같은 설치기를 다시 실행하면 복구됩니다. 원본 백업 위치는 설치 완료 메시지에 표시됩니다. 게임 파일이 지원 대상과 다르면(게임 업데이트 등) 설치를 거부하고 아무것도 바꾸지 않습니다.

저장소의 **Code → Download ZIP**은 문서와 설치기 소스 묶음입니다. 실제 설치에는 위의 패치 ZIP을 쓰세요. `installer/` 폴더만으로는 설치할 수 없습니다.

## 무엇이 바뀌나요

- 게임 폴더의 `Clicky Islands.pck` 한 파일만 바뀝니다. 실행 파일과 DLL, 저장 파일은 그대로입니다.
- 게임에 비어 있던 한국어 칸을 채우는 방식이라 영어 등 다른 8개 언어도 그대로 고를 수 있습니다.
- 언어 선택 화면과 설정의 언어 탭에 "한국어" 버튼이 생깁니다.
- 한글 글꼴로 Noto Sans KR(보통·굵게)을 넣었습니다.

## 한글화·확인 범위

언어표 **1,082칸**과 언어표 밖 직접 문구 **46개**, 무작위 섬 이름 50개를 번역했습니다. 패치된 파일을 다시 풀어 모든 칸이 번역 원본과 같은지 대조했고, 최종 ZIP의 설치·제거·복구 40개 시험을 통과했습니다.

실제 화면은 첫 화면, 설정, 기본 화면과 안내 카드, 항구, 시장, 가마솥과 화산, 섬 단계 상승, 임무 편지, 허수아비, 항해 화면(특성·화석·유물·도전 과제·통계), 게임 완료 창, 저장 불러오기를 확인했습니다. 화면에서 글자 그대로 확인한 번역문은 셀 수 있는 고유 번역 735개 가운데 222개입니다. **전체 회차와 모든 건물·분기를 플레이한 검수는 아닙니다.** 시장과 화산 창은 건물을 직접 짓지 않고 검수용 기능으로 창만 띄워 확인했고, 후반 단계의 건물 화면·괴물 둥지·강화 목록 등은 화면으로 확인하지 못했습니다.

알아 둘 점:

- 튜토리얼의 짧은 시연 영상 12종은 영어 화면을 녹화한 것이라 영상 속 글자가 영어입니다. 옆의 설명문과 목표는 한국어입니다.
- 게임 제목, 제작진 이름, 로고, 개발자 명령창은 영어 그대로입니다.
- 원작에 번역 항목이 없는 문구 일부는 원작처럼 내부 이름이 그대로 보일 수 있습니다.
- Steam의 파일 무결성 검사나 게임 업데이트 뒤에는 원본으로 돌아갑니다. 같은 빌드라면 `Install.cmd`를 다시 실행하면 됩니다.

원본 게임 파일·개인 저장·검수용 코드는 배포하지 않습니다. 게임의 권리는 원 권리자(Karrot Games, Pocketpair Publishing)에게 있으며, 포함된 도구와 글꼴의 라이선스는 패치 ZIP과 [licenses](licenses)에 있습니다. 이 저장소는 게임 제작사와 무관한 비공식 패치 배포 저장소입니다.
